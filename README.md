# Designer Tools

A collection of mini design tools built with React + Vite. Includes a mesh gradient generator, fractal glass effect, noise texture maker, and blob shape maker.

## Tools

- **Mesh Gradient** — IDW color interpolation with draggable points, palette presets, animation, and PNG export
- **Fractal Glass** — SVG `feTurbulence` + `feDisplacementMap` distortion over preset shapes or your own image
- **Noise Texture** — Tunable grain/noise overlays with blend modes
- **Blob Maker** — Organic SVG blob generator with gradient and shadow controls

## Stack

- React 19
- Vite
- Tailwind CSS 4
- Inter + Instrument Serif

## Dev

```bash
npm install
npm run dev
```
